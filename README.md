# enbi

Updated: 2026-11-09 14:14:22 CST (Asia/Taipei)

Classic PHP storefront and admin (`admin1561318`) targeting PHP 8.4 / 8.5 (formerly 7.1).

Copy `config.example.php` to `config.php` and fill local DB/mail settings. `config.php` is gitignored and must not be committed.

See `CHANGED.md` for the compatibility bootstrap. Use `scripts/php85-compat-scan.php` to re-scan removed APIs.
